# Kapao Queen

A collaborative full-stack food-ordering web application built for a Web Programming course project.

## Features

- User registration and authentication
- Browse food items and categories
- Search for items
- View detailed item information
- Create, edit, and manage menu items
- Responsive React interface
- JWT-based authentication

## Architecture

- **Frontend:** React, React Router, Axios, and styled-components
- **Backend:** Node.js and Express
- **Database:** MySQL
- **Authentication:** JWT and bcrypt

```text
Kapao-Queen-ReactApp/
├── backend/   Express API, database configuration, and SQL schema
└── frontend/  React application
```
